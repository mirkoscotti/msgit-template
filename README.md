# 🚀 msgit-template

A template repository that provides automated GitHub Actions for streamlining development workflows. Each action is documented separately for better organization and maintenance.

## 📋 Available GitHub Actions

| Action | Description |
|--------|-------------|
| 📝 **[Setup Label](.github/documents/setup-labels.md)** | Applies the standard custom label set to the repository |
| 📝 **[Triage on Issue](.github/documents/triage-on-issue.md)** | Automatically adds the triage label to new issues |
| 📝 **[Issue to Branch](.github/documents/issue-to-branch.md)** | Automatically creates branches for accepted or confirmed issues |
| 📝 **[Pull Request](.github/documents/pull-request.md)** | Automatically creates WIP Pull Requests for branches |

## 🎯 Quick Start

1. Click **"Use this template"** in the top right
2. Click **"Create a new repository"**
3. Fill in your repository details and create it
4. Click **"Settings" > "Actions" > "General"**
5. Select **"Read and write permissions"**
6. Check **"Allow GitHub Actions to create and approve pull requests"**
7. Start creating issues in the new repository - You will see ![status:triage](https://img.shields.io/badge/status:triage-F59E0B?style=flat-square) automatically!

For detailed information about each action, see the documentation links in the table above.
