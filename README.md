# 🚀 msgit-template

A template repository that provides automated GitHub Actions for streamlining development workflows. Each action is documented separately for better organization and maintenance.

## 📋 Available GitHub Actions

| Action | Description |
|--------|-------------|
| 📝 **[Setup Label](.github/documents/setup-labels.md)** | Applies the standard custom label set to the repository |

## 🎯 Quick Start

1. Click **"Use this template"** in the top right
2. Click **"Create a new repository"**
3. Fill in your repository details and create it

For detailed information about each action, see the documentation links in the table above.
